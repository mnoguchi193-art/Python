# 国家公務員 再就職状況の公表（令和6年度分）データ分析

内閣が公表する「国家公務員法第106条の25第2項等の規定に基づく国家公務員の
再就職状況の公表」（公表様式 24-2、対象期間: 令和6年4月1日〜令和7年3月31日）の
Excel ファイルを解析し、集計レポートとグラフを生成します。

## 構成

| ファイル | 内容 |
|---|---|
| `analyze.py` | 解析スクリプト本体 |
| `report.md` | 自動生成された集計レポート |
| `records.csv` | 全1,422レコード（日付シリアル値を ISO 日付へ変換、出身府省庁の推定列を追加） |
| `charts/` | グラフ画像（年齢分布・出身府省庁・再就職時期） |

## 使い方

```bash
pip install openpyxl matplotlib
python analyze.py <input.xlsx>
```

実行すると、スクリプトと同じディレクトリに `records.csv` / `report.md` /
`charts/*.png` を出力します。

## 補足

- 「出身府省庁（推定）」列は、`離職時の官職` の文字列から
  `analyze.py` の `MINISTRY_PATTERNS` に基づいて推定したものです。
  公式の分類ではない点に注意してください（全件分類済み）。
- 日付は Excel のシリアル値（1899-12-30 起点）から変換しています。
- グラフの日本語表示には IPAGothic フォントを使用しています。
