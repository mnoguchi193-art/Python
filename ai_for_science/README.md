# AI for Science (科学のための AI)

AI が科学研究をどう加速するかを、**標準ライブラリだけ**で実装した学習用デモ群です。
数値シミュレーション・データ解析・実験計画といった科学の各工程で、
機械学習がどんな役割を担うのかを、小さく動くコードで追えます。

> ⚠ **教育目的のおもちゃモデルです。** 物性値・反応収率などの数値は架空で、
> 実際のシミュレータや研究ツールの代替ではありません。

## 構成 / Modules

| File | 科学の工程 | 内容 |
|---|---|---|
| `surrogate_model.py` | シミュレーション高速化 | RK4 で解く減衰強制振動子を「高価なシミュレータ」とみなし、手書き逆伝播の MLP で代理モデル化。1000 倍超の高速化で共鳴周波数を探索 |
| `equation_discovery.py` | 法則の発見 | SINDy 風のスパース回帰 (STLSQ)。時系列データだけからロジスティック成長と Lotka-Volterra 方程式を再発見 |
| `bayesian_optimization.py` | 実験計画 (自動実験室) | ガウス過程 + Expected Improvement で反応温度を 15 回の実験で最適化。ランダム探索と比較 |
| `inverse_design.py` | 材料の逆設計 | 「性質 → 構造」の逆問題を、順方向モデル上の進化的探索として解く。目標バンドギャップと希少元素制約 |
| `transit_search.py` | 大規模データからの信号検出 | ノイズと恒星変動を含む光度曲線から Box Least Squares で系外惑星トランジットを検出し、惑星半径を推定 |

## 実行 / Run

```bash
python3 ai_for_science/surrogate_model.py         # ~6 s (学習込み)
python3 ai_for_science/equation_discovery.py
python3 ai_for_science/bayesian_optimization.py
python3 ai_for_science/inverse_design.py
python3 ai_for_science/transit_search.py
```

外部ライブラリ不要 (標準ライブラリのみ)。各ファイルは独立しており、相互 import はありません。

## 5 つのパターン / The five patterns

科学における AI の使い方は、だいたい次の 5 パターンに整理できます。

1. **代理 (Surrogate)** — 高価な計算を一度だけたくさん走らせ、その入出力を学習した
   モデルで置き換える。気候モデルや第一原理計算のエミュレータがこれ。
2. **発見 (Discovery)** — データから人間が読める方程式を取り出す。ブラックボックス予測
   ではなく「法則」を返すのが要点。スパース性 (項を少なく) が鍵。
3. **計画 (Design of experiments)** — 次にどの実験をすべきかをモデルの不確かさから決める。
   「よさそうな所を掘る」と「まだ見ていない所を調べる」のバランスを取る。
4. **逆設計 (Inverse design)** — 欲しい性質から構造を逆引きする。順方向モデル (1 や
   シミュレータ) を最適化ループの中で何千回も呼ぶ。
5. **検出 (Detection)** — 人間が全件を見られない量のデータから、弱い信号を自動で拾う。
   天文・素粒子・ゲノムで共通する課題。

これらは独立ではなく連鎖します: 1 で高速化したモデルを 4 の探索に使い、3 で選んだ実験
の結果を 2 で法則にまとめ、5 で見つけた対象をまた 1 でモデル化する —— この循環が
「AI for Science」の全体像です。
