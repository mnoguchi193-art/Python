# 新しい心理現象は再現できるのか / Can new psychological phenomena be replicated?

心理学の**再現性危機 (replication crisis)** を、統計シミュレーションで解剖する
学習用デモ群です。検出力・出版バイアス・p ハッキング・陽性的中率を標準ライブラリ
だけでシミュレートし、「なぜ多くの新奇な心理現象が追試で再現しないのか」、そして
「どうすれば再現性を取り戻せるのか」を数値で示します。

> ⚠ **教育目的の簡略モデルです。** 正規近似の z 検定を用い、パラメータは
> 説明用の設定です。実証データの推定値ではありません。

## 構成 / Modules

| File | 内容 |
|---|---|
| `study.py` | 共有コア。2群比較の検定・p値・検出力 (正規分布 via `math.erf`) |
| `publication_bias.py` | 出版バイアスと勝者の呪い。効果量の誇張・ファンネルプロット |
| `p_hacking.py` | 研究者の自由度が偽陽性率を 5%→40%超に膨らませる (分岐する庭) |
| `replication.py` | 陽性的中率 (Ioannidis) と再現プロジェクトの模擬・改善策の比較 |

## 実行 / Run

```bash
python replication_crisis/study.py             # 検出力と検定の基礎
python replication_crisis/publication_bias.py   # 出版バイアス
python replication_crisis/p_hacking.py          # p ハッキング (やや時間がかかる)
python replication_crisis/replication.py        # 再現率と改善策
```

外部ライブラリ不要 (標準ライブラリのみ)。各モジュールは `study` を import する
ため、`replication_crisis/` をカレントに実行してください。

## 危機の解剖 / Anatomy of the crisis

1. **検出力不足** (`study.py`) — 典型的な心理学研究 (n≈25/群, d≈0.35) の検出力は
   わずか ≈24%。真の効果すら大半を見逃す。
2. **出版バイアス** (`publication_bias.py`) — 有意な結果だけが出版されると、公表される
   効果量は真の値を大きく上回る (検出力が低いほど誇張が激しい=勝者の呪い)。
3. **研究者の自由度** (`p_hacking.py`) — 覗き見・複数指標・サブグループを組み合わせると、
   真の効果ゼロでも偽陽性率は 5%→40%超に。悪意なしの善意の裁量で起きる。
4. **陽性的中率と再現率** (`replication.py`) — 上記が重なると「有意な発見が真である確率」は
   低下し、現行実務の再現率は ≈38% (OSC 2015 の ≈36% に符合)。前登録・高検出力・
   厳しいα・有望な仮説の検証を重ねると ≈84% まで改善する。

## 結論 / The answer

現行の慣行のままでは、新奇な心理現象の多くは**再現しない**。だが原因は人間心理の
気まぐれ以前に、**低検出力・出版バイアス・研究者の自由度という「方法の問題」**にある。
これらは研究の設計で修正可能であり、**再現性は宿命ではなく、選べる帰結である**——
というのが一連のシミュレーションが示すメッセージです。
