# AI Scientist (AI 科学者)

**自律的に研究サイクルを回す AI** の中核コンポーネントを、標準ライブラリだけで実装
した学習用デモ群です。個々の機械学習手法 (`ai_for_science/` を参照) ではなく、
「仮説を立て → 実験を設計し → 結果を分析し → 自己査読し → 報告する」という
**研究そのものを回すループと意思決定**に焦点を当てます。

> ⚠ **教育目的のおもちゃモデルです。** 隠された法則・データはすべて架空で、実在の
> 研究自動化システム (Sakana AI の "The AI Scientist" 等) の再現・代替ではありません。

## 構成 / Modules

| File | 研究の工程 | 内容 |
|---|---|---|
| `hypothesis_search.py` | 仮説の生成と選択 | 競合する関数形を最小二乗で当てはめ、BIC で順位付け (自動オッカムの剃刀) |
| `active_experiment.py` | 実験の設計 | 理論どうしが最も食い違う条件を選ぶ能動的実験計画。ベイズ更新でランダム法と比較 |
| `automated_review.py` | 自己査読 | 主張を有意性・効果量・検出力・頑健性で審査し accept/reject を判定 |
| `research_loop.py` | 全体の統合 | 仮説→実験→再当てはめ→判断→報告を自律的に回し、隠された法則を発見 |

## 実行 / Run

```bash
python3 ai_scientist/hypothesis_search.py
python3 ai_scientist/active_experiment.py
python3 ai_scientist/automated_review.py
python3 ai_scientist/research_loop.py
```

外部ライブラリ不要 (標準ライブラリのみ)。各ファイルは独立しており、相互 import は
ありません (`research_loop.py` は必要な部品を内部に再実装しています)。

## 研究を自動化するということ / Closing the loop

科学の進歩は「仮説 → 実験 → 分析 → 次の仮説」というループです。AI Scientist は
このループの各段を自動化し、人間より速く回そうとします。

1. **仮説 (`hypothesis_search.py`)** — データに合う説明を複数立て、単純さと当てはまりの
   両立で選ぶ。ノイズに過剰適合した複雑なモデルは BIC の罰則で退けられる。
2. **実験 (`active_experiment.py`)** — 次に何を測るかが鍵。手当たり次第ではなく、
   仮説どうしが最も割れる「決定的な質問」を選ぶと、少ない実験で真実に至る。
3. **査読 (`automated_review.py`)** — 発見を報告する前に自分を疑う。「有意だが些細」
   「有望だが検出力不足」を見抜き、脆い結論を弾く。
4. **統合 (`research_loop.py`)** — 1〜3 を閉じたループにつなぐと、何も教えられて
   いない法則を、自分で実験を設計しながら発見できる。

鍵となるのは **2 の「何を測るか」の選択**です。知識を増やすのは答えではなく、良い問い。
AI Scientist が人間の研究を加速しうるのは、この問いの設計を高速に繰り返せるからです。
