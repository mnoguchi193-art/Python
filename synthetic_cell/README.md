# 人工合成細胞 / Synthetic Cells

人工的に設計・合成される最小細胞 (synthetic minimal cell) と、その構成要素を
**標準ライブラリだけ**で実装した学習用デモ群です。合成生物学の代表的な遺伝子回路
から、代謝・ゲノム・分裂・原始細胞まで、「細胞を部品から組み立てる」という視点で
計算モデルを追えます。

> ⚠ **教育目的のおもちゃモデルです。** 速度定数・代謝経路・物性値はすべて架空で、
> 実際の細胞や JCVI-syn3.0 等の合成生物学ツールを再現・代替するものではありません。

## 構成 / Modules

| File | テーマ | 内容 |
|---|---|---|
| `gene_circuits.py` | 合成遺伝子回路 | トグルスイッチ (双安定=1ビット記憶) とリプレッシレーター (遺伝子による発振回路)。Hill 関数 + RK4 |
| `metabolism.py` | 代謝 | Michaelis-Menten 酵素反応、飽和曲線、2段階経路 S→A→B の律速 |
| `minimal_genome.py` | 最小ゲノム | 代謝ネットワーク上の遺伝子必須性解析 (1遺伝子ノックアウト) と貪欲法による最小ゲノム構築 |
| `cell_division.py` | サイズ恒常性 | 「アダー (adder)」モデル。一定体積を足して分裂するだけでサイズが安定することを示す |
| `protocell.py` | 原始細胞 | 脂質小胞の表面積/体積比による自発的分裂。幾何だけで成立する遺伝子なしの複製周期 |

## 実行 / Run

```bash
python3 synthetic_cell/gene_circuits.py
python3 synthetic_cell/metabolism.py
python3 synthetic_cell/minimal_genome.py
python3 synthetic_cell/cell_division.py
python3 synthetic_cell/protocell.py
```

外部ライブラリ不要 (標準ライブラリのみ)。各ファイルは独立しており、相互 import は
ありません。

## 「細胞を作る」ための 5 つの問い / Five questions in building a cell

人工合成細胞をゼロから設計するとき、だいたい次の問いに答えることになります。本 demo
群はそれぞれに対応します。

1. **どう判断・記憶するか** (`gene_circuits.py`) — 遺伝子どうしの抑制だけで、状態を
   記憶する (トグル) 時を刻む (リプレッシレーター) といった計算ができる。細胞の
   「論理回路」。
2. **どうエネルギーと材料を作るか** (`metabolism.py`) — 酵素は飽和する弁。経路全体の
   速度は一番遅い酵素が決める。生命の化学の最小単位。
3. **どの遺伝子が必須か** (`minimal_genome.py`) — 生きるのに最低限必要な遺伝子集合は
   何か。バックアップ経路がある遺伝子は削れる。最小ゲノム研究の計算核。
4. **どうサイズを保つか** (`cell_division.py`) — 分裂の度にサイズがばらつかないのは
   なぜか。サイズを測らず「一定量を足す」だけで恒常性が生まれる。
5. **そもそもどう分裂を始めるか** (`protocell.py`) — 遺伝子も酵素もない膜小胞でも、
   表面積と体積の幾何的な不均衡だけで二つに割れる。生命以前の自己複製。

1→5 の順に「高度な制御」から「最も原始的な物理」へと降りていくと、合成細胞が
「遺伝子回路・代謝・膜」という層の重ね合わせであることが見えてきます。
